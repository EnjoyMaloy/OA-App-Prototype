# Черновики экранов

Быстрые прототипы новых экранов на чистом HTML — до переноса в приложение.
Бэкенд не нужен: данные пишутся прямо в разметке, логика — на нескольких строках JS.

## Как устроено

- `kit.css` — повторяющиеся блоки экранов (каркас, карточки, кнопки, плитки, таб-бар, заметки).
- `build.mjs` — собирает черновик в самодостаточный файл: подставляет шрифты TT Commons,
  токены `:root`/`.dark` и типографику **из `src/index.css`**, а следом `kit.css`.
  Токены не копируются, поэтому черновик всегда совпадает с текущим приложением.
- `kit-demo.html` — образец: что есть в ките и как это выглядит.

## Как сделать черновик

1. Скопировать `kit-demo.html` в `prototypes/<экран>.html`.
2. Писать **фрагментом**: `<title>`, потом разметка. Без `<!doctype>`, `<html>`, `<head>`, `<body>` —
   их добавляет хостинг артефактов, и сборщик на них ругается.
3. Собрать и посмотреть:

```bash
node prototypes/build.mjs prototypes/<экран>.html
```

Готовый файл появится в `dist-prototypes/` (в git не попадает) — его можно открыть локально
или опубликовать артефактом, чтобы посмотреть с телефона.

## Правила

- Вопросы по логике — в `<p class="note">`: что по тапу, откуда данные, какие состояния.
  В приложение заметки не переносятся.
- Внешняя сеть в артефактах закрыта: картинки — только `data:` URI или заглушки,
  шрифты уже вшиты сборщиком.
- Черновик — не исходник продукта. Одобренный экран переносится в `src/pages` на React,
  а файл черновика остаётся историей решения.
